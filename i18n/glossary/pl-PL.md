# Glossary: Polish (Polski, pl-PL)

Read together with [`_shared.md`](_shared.md). Binding for every translation into this
language: use these terms consistently. Reviewers: correct this file when a term is
wrong, the agent will follow it from then on.

## Style

- Form of address: informal 2nd person singular ("Wybierz", "Twój"), as in the Joomla pl-PL core translation (agent decision, please review). Masculine past forms are used where Polish needs a gender ("Przejrzałem"); a reviewer may prefer neutral wording.
- Counts are written as "label: %d" where Polish plural forms would otherwise depend on the number.
- Joomla terms follow the official pl-PL core translation (Konfiguracja globalna, Kokpit).
- Tone: concise UI language, as in the Joomla core translation for this language.
- TUF terms root, targets, snapshot, timestamp and the role and group names (TUF_ED Owner,
  TUF_EDC Signer, TUF_ED Auditor, Owner, Signer) stay in English, see `_shared.md`.
