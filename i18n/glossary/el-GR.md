# Glossary: Greek (Ελληνικά, el-GR)

Read together with [`_shared.md`](_shared.md). Binding for every translation into this
language: use these terms consistently. Reviewers: correct this file when a term is
wrong, the agent will follow it from then on.

## Style

- Form of address: formal plural ("Επιλέξτε") (agent decision, please review).
- Greek question mark is ; and the ano teleia · is used as semicolon.
- Joomla terms follow the official el-GR core translation where known (Γενικές ρυθμίσεις, Υπερχρήστες, Εφαρμογές for Components). Plugin names (System - Debug) and some technical words (component, online/offline, cache, hash) were left in English and should be checked.
- Tone: concise UI language, as in the Joomla core translation for this language.
- TUF terms root, targets, snapshot, timestamp and the role and group names (TUF_ED Owner,
  TUF_EDC Signer, TUF_ED Auditor, Owner, Signer) stay in English, see `_shared.md`.
